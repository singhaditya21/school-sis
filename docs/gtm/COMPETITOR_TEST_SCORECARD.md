# Competitor Test Scorecard

## Objective

Compare the buyer experience and implementation risk of Entab, Edunext, Teachmint, Fedena, PowerSchool/Neverskip, and Classplus using the same evidence and workflows. Marketing copy alone does not earn a score above 1.

## Evidence hierarchy

| Level | Evidence |
| ---: | --- |
| 0 | No evidence found |
| 1 | Public marketing claim |
| 2 | Documentation, recorded demo, or current help content |
| 3 | Live product demonstration or trial |
| 4 | Customer or implementation reference |
| 5 | Repeated proof across product and multiple references |

## Required workflows

### Workflow A — onboard and reconcile

Import a representative student, invoice, payment, waiver, refund, and settlement dataset. Record mapping effort, validation, duplicates, rerun behavior, variance handling, audit evidence, and time to reconciled output.

### Workflow B — control a sensitive exception

Initiate a waiver or refund, route approval, enforce authorization, capture comments/evidence, reject or approve, and inspect the immutable history.

### Workflow C — report across campuses

Compare billed, collected, outstanding, aging, exceptions, waivers/refunds, reconciliation status, and unexplained variance by campus and group.

## Scorecard dimensions

Score each dimension 0–5 and attach evidence:

1. Data import and mapping.
2. Reconciliation integrity.
3. Exception visibility.
4. Approval and audit controls.
5. Multi-campus reporting.
6. Coexistence and integration.
7. Implementation effort.
8. Security and procurement evidence.
9. Support and migration confidence.
10. Pricing transparency and commercial flexibility.

## Claim register

Each external ScholarMind claim must be classified:

- **Proven advantage** — repeatable ScholarMind evidence and competitor comparison exist.
- **Parity** — necessary capability, not differentiation.
- **Hypothesis** — plausible but requires product/customer proof.
- **Contradicted** — evidence shows the claim is false or already common.
- **Retired** — removed from sales material.

## Completion gate

Six completed scorecards, three tested workflows per competitor, screenshots or structured demo notes, eight reference interviews, and a battlecard for each competitor. Unknowns remain visible; they are not scored as zero or converted into claims.
